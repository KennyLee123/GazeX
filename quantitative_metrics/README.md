### **Calculate TP,FN and FP of model inference results and radiologists' examination results**  
1. Prepare inference results from model and radiologists' examination results by following the provided JSON format **compare_gazex_radiologists_examination.json**.


### **Calculate and Plot the correlation between model's attention centriods and radiologists' attention centriods**  
1. Prepare all_bboxes_and_centroids.csv, which includes columns and contents extracted from the REFLACX dataset:

| Column      | Description | 
|---------------------------|----------------------|
| id | Study ID from the REFLACX dataset  | 
|sentence| One sentence that a radiologist used to describe the chest X-ray image |
| patch_idx | The sequence number of the sentence |
| x_min,y_min,x_max,y_max | X and Y coordinates of the bounding box of the attention area |
| centroid_x,centroid_y | X and Y coordinates of the attention centriods |

2. Prepare model_inference_result_attention_centroids.json, which contains Chest X-ray descriptions generated by the model and the corresponding attention centroid coordinates for each description.

3. Run:
```bash
python compare_gazex_radiologist_attention_centriods.py
```
