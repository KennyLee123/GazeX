## 1. Clone the Repository

Clone the GazeX repository to your local machine using the following command:

```bash
git clone https://github.com/KennyLee123/GazeX.git
```

## 2. Environment Setup

| Installation Script       | Python | 
|---------------------------|----------------------|
| `gazex_env_installation.sh`| Python 3.10.0  | 


### Setup Instructions

1. Navigate to the cloned repository directory:
   ```bash
   cd GazeX/environments
   ```

2. Run the installation script:
   ```bash
   bash gazex_env_installation.sh
   ```

   This will install the required dependencies.
